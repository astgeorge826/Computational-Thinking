Writing algorithms

Sequence

Instructions run in order.
INPUT age
OUTPUT age

Selection

Choose a path based on a condition.
IF score >= 50 THEN
 OUTPUT "Pass"
ELSE
 OUTPUT "Try again"
ENDIF

Iteration

Repeat instructions.
FOR i = 1 TO 5
 OUTPUT i
ENDFOR
